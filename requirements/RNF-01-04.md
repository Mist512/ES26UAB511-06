## ID
RNF-01-04
## Type/Category
No funcional / Gestió de comptes i creació de perfils d’usuari
## Version
2.0
## Title
Repetició dins del sistema
## Description
El nom de ususari no podrà estar repetit dins del sistema.
## Precondicions
L’usuari està en el procés de registre o edició del nom d’usuari.
## Postcondicions
El sistema verifica la unicitat del nom i el desa si no hi ha duplicats.
## Excepcions
Si el nom d’usuari ja existeix, el sistema mostrarà un error i suggerirà alternatives.
