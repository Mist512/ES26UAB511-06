RNF-06-04
## Type/Category
No funcional / Funcionalitats addicionals
## Version
2.0
## Title
Disponibilitat en web i mòbil
## Description
L’aplicació tindrà dues versions: web i mòbil.
## Precondicions
Ambdues versions han d’estar desplegades i accessibles.
## Postcondicions
L’usuari pot accedir a totes les funcionalitats de l’aplicació tant des del navegador web com des de l’app mòbil.
## Excepcions
Algunes funcionalitats poden tenir limitacions específiques en una de les dues versions per restriccions de plataforma.
