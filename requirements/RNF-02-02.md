## Type/Category

## Version
2.0
## Title
Límit de comandes actives per client
## Description
Un mateix client no podrà tenir més de tres comandes actives alhora.
## Precondicions
L’usuari ha d’estar autenticat i intentar realitzar una nova comanda.
## Postcondicions
El sistema verifica el nombre de comandes actives i bloqueja la nova comanda si se supera el límit de tres.
## Excepcions
Si el sistema no pot verificar l’estat de les comandes actives per un error tècnic, s’ha de mostrar un missatge d’error i no permetre la nova comanda fins a la recuperació.
