## Title
Protocol d’encriptació de dades
## Description
Es farà servir el protocol OpenVPN per encriptació de dades.
## Precondicions
La infraestructura de xarxa ha d’estar configurada amb OpenVPN.
## Postcondicions
Totes les comunicacions de dades sensibles van encriptades mitjançant OpenVPN.
## Excepcions
Si el servei OpenVPN no és accessible, les comunicacions no es podran establir de forma segura i el sistema ha d’aturar les transmissions de dades sensibles.
